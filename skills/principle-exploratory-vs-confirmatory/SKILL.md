# Exploratory Vs Confirmatory

Confirmatory claims need a hypothesis and analysis plan written before the data is examined. Everything else is exploratory.

- Write the plan (primary endpoint, test, alpha, exclusions) in the design note before touching outcome data.
- Record every departure from the plan as a deviation with the reason.
- Label post-hoc findings as hypotheses for a new study, not results.
- Correct for multiplicity across everything you looked at, not only what you report.
