# Caption States the Conclusion

A reader should get the takeaway from the caption alone. This applies when writing papers and manuscripts, not to working figures.

1. **The finding**, as one sentence the figure defends. Not "Figure 3 shows Y against X", but "Y falls linearly with X (slope −0.42, 95% CI [−0.48, −0.36]; n = 184)".
2. **The elements** that are not obvious: what each colour, line and shaded band is.
3. **The statistics**: n, the test, and what the spread is (SD, SEM or CI). Report the effect size or p value, not only asterisks; define any asterisk.
4. **Panel keys** for a multi-panel figure: (a) … (b) …

Units in the caption match the axes. In the text, refer to "Fig. 3a", never "the figure below". Every figure is interpreted in the body text, not left as decoration.
