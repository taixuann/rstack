# Prompting research-mode

State the goal and how you will know it is done. Don't list skills or steps. The mode picks the playbook.

- Good: `/research-mode design a within-subject study comparing two ECG patch placements, 20 subjects, primary endpoint R-peak detection error. Output a design note with sample size.`
- Weak: `/research-mode use experimental-design then statistical-power then write it up.`

Include: the question, the data or folder, the constraint (journal, deadline, sample limit), and the check ("every number in the draft traces to a file").

Add the autonomy signal when you step away: "run until done, log decisions, don't touch data/raw."
