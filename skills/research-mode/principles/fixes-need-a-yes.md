# Fixes Need a Yes

- Mechanical means citation format, unit format, spelling and typos. Wording, order and emphasis are not mechanical.
- List each fix on one line: file, line, before, after.
- Apply only the fixes the user accepts, each exactly as listed.
- A fix that would change a number or a meaning is not mechanical. Ask a question instead.
