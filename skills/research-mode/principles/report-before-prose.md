# Report Before Prose

- A number, unit, uncertainty, method fact or citation enters the draft only after it is in `docs/reports/<topic>/` with its source.
- Copy values with the digits the source file has. Never round, convert or derive one in the report by hand.
- A number worked out in the prose (a percent change, a ratio) is not in the report. The analysis adds it first.
- After approval the evidence files are read-only. A change means going back to Paper preparation.
- Check with the script, not by eye.
