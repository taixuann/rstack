## Understanding

Kept by `evaluate-my-understanding`, at the end of each ingested page in Notion. Levels: 0 not met, 1 recognise, 2 explain in own words, 3 apply to a new case, 4 critique a claim. A level of 2 or more needs an evidence link to the Raw page that holds the user's answer. The level changes only when a test page is ingested.
