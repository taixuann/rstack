### Multi-phase plan

A study that spans phases (pilot, main, replication) or several deliverables.

1. Write the phases with an exit check for each, riskiest unknown first.
2. Save the plan in `analysis/plan.md`. Freeze it before running phase 1.
3. Run one phase at a time with the playbook that fits it. Save outputs in their home folders.
4. After each phase, compare results with the plan and record any change as a deviation.

**Reply:** the plan, the current phase, and the next check.
