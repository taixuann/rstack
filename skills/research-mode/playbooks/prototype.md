### Prototype

A throwaway pilot that settles an empirical fork by observing it instead of asking the human ("try it on one subject", "does this filter help", "sketch the figure").

1. Name the fork and the observation that would decide it.
2. Build the smallest script on a small slice. Label the output `PILOT, not for reporting`.
3. Run it, read the result, decide. Do not carry pilot code into `analysis/` without review.
4. Record the decision and the evidence in the design note or decision log.

**Reply:** the fork, what the pilot showed, and the decision.
