### Authoring or modifying a skill or playbook

Writing or editing a SKILL.md or a playbook.

1. Use the `skill-creator` skill when available.
2. Validate: frontmatter has `name` and `description`, referenced files exist, cross-skill links resolve (`claude plugin validate`).
3. When in doubt, delete. Keep only prose that changes a decision. Point at structural sources; do not restate other skills.
4. A workflow you keep hitting but is not captured: use `/reflect`. If it is one-off, use `figure-it-out` instead.

**Reply:** what the skill does, key design decisions, and validation notes.
