# Question First

State the question and the decision it supports in one sentence each before work starts. If you cannot, the work is not ready.

**Why:** Methods chosen before the question get bent to fit it. A named decision tells you which precision, sample size, and rigor are enough.

- Name the smallest output that answers the question, and stop there.
- If the evidence rules out the question as asked, show it and reframe instead of answering the wrong one.
- Restate the question in every worker brief and at the top of every report.
