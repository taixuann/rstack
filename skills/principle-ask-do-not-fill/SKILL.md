# Ask, Do Not Fill

- A missing item is written as `TODO: unknown` and the user is asked.
- Never invent a measurement, citation, parameter, threshold or metadata.
- A missing measurement is a gap with an owner. It goes back to the analysis and is never taken from a chat answer.
- Ask one topic at a time, in short rounds.
- An item the user has not confirmed stays out of the report.
