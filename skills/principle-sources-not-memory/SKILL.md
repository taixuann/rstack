# Sources Not Memory

- Resolve every citation against a database (DOI, PubMed, arXiv, OpenAlex) before it enters a draft.
- Copy constants and prior results from the source, with the page or table.
- Mark abstract-only reads as such. List a paper as read only if you read it.
- Never fabricate a reference, quote, or measurement. A missing source is a gap to report.
