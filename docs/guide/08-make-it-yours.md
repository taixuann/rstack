# Make it yours

- Run `/setup-research` again to change defaults or models.
- Run `/reflect` after substantial work. Three reviewers read the session and propose edits: add, change, or retire playbooks. Nothing changes until you approve.
- When you correct the same mistake twice, run `/correct`. It fixes the class with structure, a template, or a check script before it writes a rule.
- Validate changes with `claude plugin validate rstack`.
