# Set up rstack

1. Install: `/plugin marketplace add <path to research-space>`, then `/plugin install rstack@research-space`.
2. Run `/rstack:setup-research`. It writes `research-profile.md` (citation style, statistics defaults, figure conventions) in the research-space root and, if you want, `~/.claude/rules/rstack-models.md`.
3. Open a project and start with `/rstack:research-mode`.

Installing changes nothing until you invoke a skill.
