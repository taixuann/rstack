# The rstack guide

rstack works best when you describe the goal and how you will know it is done. `/research-mode` states the question, picks the playbook, runs other skills as the steps need them, and shows the evidence.

1. [Set up rstack](./01-setup.md). Install, profile, models.
2. [Route work through `/research-mode`](./02-research-mode.md). Give it a goal and watch it pick a playbook.
3. [Scaffold and design](./03-scaffold-and-design.md). Folder blueprint, hypotheses, power.
4. [Analyse and verify](./04-analyse-and-verify.md). Data, figures, numbers you can trace.
5. [Literature and writing](./05-literature-and-writing.md). Wiki, citations, manuscripts, reviews.
6. [Steer with principle names](./06-principles.md). Names that redirect an agent mid-task.
7. [Make it yours](./07-make-it-yours.md). Your own playbooks with `figure-it-out`.

Stuck? Type `/research-help` with your question.

If you remember one thing, give a goal and a check:

```text
/research-mode compare two ECG patch placements on R-peak detection error. design first, 20 subjects, every number traced to a file.
```
