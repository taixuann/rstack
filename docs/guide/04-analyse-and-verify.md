# Analyse and verify

The Study analysis playbook reads the plan, inspects the data, runs the pre-stated tests, adds one sensitivity check, and saves scripts, figures, and `analysis/results.md`.

Before a number is reported, **explain-the-number** asks what limits it and what else it could be measuring. Post-hoc findings are labelled. Use Reproduce to re-run a published result, Data forensics for artifacts, and Hillclimb for sustained metric improvement.
